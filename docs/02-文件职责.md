# 02 · 文件职责清单

> 用途：改代码前先在这里定位目标文件，避免整仓 grep 和反复通读。
> 规则：新增文件或职责变化时同步更新本表；每行一句话。
> 最后更新：阶段 ④（2026-11-12）

## src/main（主进程）

| 文件 | 职责 |
| --- | --- |
| `src/main/index.ts` | 创建 Electron 窗口、注册 IPC、开发/生产加载入口。 |
| `src/main/menu.ts` | 应用菜单与「打开 CSV」等菜单项。 |
| `src/main/ipc/file.ts` | 通过原生对话框读文件并把文本回传给渲染进程。 |

## src/preload

| 文件 | 职责 |
| --- | --- |
| `src/preload/index.ts` | 用 contextBridge 暴露最小的文件读取 API。 |

## src/shared（主/渲染共用，纯逻辑）

| 文件 | 职责 |
| --- | --- |
| `src/shared/types/shmoo.ts` | 领域模型：数据集、站点、轴、spec、单元状态常量。 |
| `src/shared/types/api.ts` | 主进程 ↔ 渲染进程的 IPC 类型。 |
| `src/shared/csv/tokenize.ts` | 轻量 CSV 分词（引号、转义、CRLF）。 |
| `src/shared/csv/metadata.ts` | 从表头/注释解析轴、站点、单位与元信息。 |
| `src/shared/csv/validate.ts` | 逐行校验与问题汇总（R1–R17 规则）。 |
| `src/shared/csv/parser.ts` | 长表 → 2D/1D 网格、缺测统计、通过率、spec 应用。 |
| `src/shared/spec/evaluate.ts` | 单点判定：状态、margin、spec 完整性。 |

## src/renderer/chart（画布与纯几何）

| 文件 | 职责 |
| --- | --- |
| `chart/geometry.ts` | 绘图区、格子矩形/中心、命中测试、刻度抽稀、小数位。 |
| `chart/colors.ts` | A′ 单一色板、margin 明度调制、热力渐变、面积图配色。 |
| `chart/render2d.ts` | 2D 三层绘制：静态层（色块/轴/图例/切片标记）、边界层、交互层（十字线/整行提示）。 |
| `chart/oneD.ts` | 1D 纯计算：序列提取、PASS 区间、主窗口、值域与刻度、hover 吸附。 |
| `chart/render1d.ts` | 1D 两种形态绘制：二值色带（窗口边界）与连续曲线（spec 线/越界点）。 |
| `chart/slice.ts` | 2D → 1D 切片：序列提取、包装成 1D 数据集、最差 margin。 |
| `chart/useLayeredCanvas.ts` | 三层 canvas 的尺寸同步、DPR、rAF 合并重绘。 |
| `chart/perf.ts` | 重绘耗时统计（仅开发模式写 `window.__shmooPerf`）。 |

## src/renderer/components

| 文件 | 职责 |
| --- | --- |
| `components/ChartStage.tsx` | 图表区总装：工具栏、标题、面包屑、2D/1D/切片分支与空态。 |
| `components/Shmoo2DChart.tsx` | 2D 交互：hover 浮层、整行提示、双击切片、动效入场。 |
| `components/Shmoo1DChart.tsx` | 1D 交互：hover 吸附 tooltip、入场动效、reduced-motion 降级。 |
| `components/SiteRail.tsx` | 左侧站点列表与数据集摘要、导入报告。 |
| `components/SpecPanel.tsx` | 右侧规格面板；切片时改显示该曲线的最差 margin 与通过区间。 |
| `components/StatusBar.tsx` | 底部状态栏：解析状态、真实统计、耗时。 |
| `components/TitleBar.tsx` | 自定义标题栏与「打开 CSV」按钮。 |

## src/renderer 其他

| 文件 | 职责 |
| --- | --- |
| `renderer/App.tsx` | 三栏布局骨架。 |
| `renderer/main.tsx` | React 挂载入口，开发模式挂演示数据。 |
| `renderer/state/store.ts` | zustand 全局状态：数据集、站点、spec、配色、1D 形态、切片。 |

| `renderer/dev/demo.ts` | 开发演示数据集与 `?demo/?hover/?slice` 调试参数。 |
| `renderer/env.d.ts` | Window 上的开发自检字段类型声明。 |
| `renderer/theme/tokens.css` | 颜色、字号、间距、时长等设计令牌。 |
| `renderer/styles/app.css` | 全部布局与组件样式（含 crumb、stat 等）。 |
