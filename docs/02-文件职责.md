# 02 · 文件职责清单

> 用途：改代码前先在这里定位目标文件，避免整仓 grep 和反复通读。
> 规则：新增文件或职责变化时同步更新本表；每行一句话。
> 最后更新：阶段 ④ 补齐（2026-11-12，双边 spec / min==max / 二值降级）

## src/main（主进程）

| 文件 | 职责 |
| --- | --- |
| `src/main/index.ts` | 创建 Electron 窗口、注册 IPC、开发/生产加载入口。 |
| `src/main/menu.ts` | 应用菜单与「打开 CSV」等菜单项。 |
| `src/main/ipc/file.ts` | 通过原生对话框读文件并把文本回传给渲染进程。 |

## src/preload

| 文件 | 职责 |
| --- | --- |
| `src/preload/index.ts` | 用 contextBridge 暴露最小的文件读取 API。 |

## src/shared（主/渲染共用，纯逻辑）

| 文件 | 职责 |
| --- | --- |
| `src/shared/types/shmoo.ts` | 领域模型：数据集、站点、轴、spec（window/min/max/none）、margin 撞边侧、单元状态常量。 |
| `src/shared/types/api.ts` | 主进程 ↔ 渲染进程的 IPC 类型。 |
| `src/shared/csv/tokenize.ts` | 轻量 CSV 分词（引号、转义、CRLF）。 |
| `src/shared/csv/metadata.ts` | 从表头/注释解析轴、站点、单位与元信息；spec 支持 min/max/双边/min==max/none，拒绝带单位数值。 |
| `src/shared/csv/validate.ts` | 逐行校验与问题汇总（R1–R17 规则）。 |
| `src/shared/csv/parser.ts` | 长表 → 2D/1D 网格、缺测统计、通过率、spec 应用；为阶段 ⑥ 额外保留每格 CSV pass 列原始值（`sourcePass`），保证改 spec 后能复现重新解析结果。 |
| `src/shared/spec/evaluate.ts` | 单点判定：状态、margin 与撞边侧、spec 完整性；二值域/零宽窗口/热力可用性判断；`isFlatBinaryDataset` 一次性判定“是否走平涂配色”。 |
| `src/shared/spec/apply.ts` | 阶段 ⑥：在已解析数据集上应用新 spec，只重算 `pass/passCount`、不动 value；按 derived / pass_source=file / passfail 三种口径与 parser 保持一致；`isSameSpec` 忽略无意义差异。 |
| `src/shared/spec/input.ts` | 阶段 ⑥：规格输入解析与校验（只填一边、双边、min==max；拒绝两空/非数字/min>max），以及模式文案与数值→文本格式化。 |

## src/renderer/chart（画布与纯几何）

| 文件 | 职责 |
| --- | --- |
| `chart/geometry.ts` | 绘图区、格子矩形/中心、命中测试、刻度抽稀、小数位。 |
| `chart/colors.ts` | 两套色板：连续值用 A′（anchor/shadow + margin 明度调制），纯二值用中间档 `#2DAF72`/`#E04037` 平涂；热力渐变、面积图配色、边界/十字线/vignette 结构色。 |
| `chart/render2d.ts` | 2D 三层绘制：静态层（圆角单元格 + 1px 格缝、轴、图例、噪点、切片标记）、边界层（阶梯 1px 边界 + 可选氛围动效）、交互层（十字准线/涟漪/整行提示/锁定描边/框选矩形）。 |
| `chart/interaction.ts` | 交互纯逻辑：浮层四边翻转与夹紧、键盘移动/Home/End、框选归一化与区域统计、单击/双击 250ms 判定。 |
| `chart/oneD.ts` | 1D 纯计算：序列提取、PASS 区间、主窗口、窗口边界（双边 4 个）、值域与刻度、hover 吸附。 |
| `chart/render1d.ts` | 1D 两种形态绘制：二值色带（圆角竖条 + 1px 缝、4 个边界值）与连续曲线（上下 spec 线 + ▲/▼ 越界点，二值数据下点色切到系统色）。 |
| `chart/slice.ts` | 2D → 1D 切片：序列提取、包装成 1D 数据集、最差 margin（含撞边侧）。 |
| `chart/useLayeredCanvas.ts` | 三层 canvas 的尺寸同步、DPR、rAF 合并重绘。 |
| `chart/perf.ts` | 重绘耗时统计（仅开发模式写 `window.__shmooPerf`）。 |

## src/renderer/components

| 文件 | 职责 |
| --- | --- |
| `components/ChartStage.tsx` | 图表区总装：工具栏（二值数据时热力置灰、「氛围动效」开关）、标题、面包屑、2D/1D/切片分支与空态。 |
| `components/Shmoo2DChart.tsx` | 2D 交互：hover 浮层（四边翻转）、单击锁定/取消、双击切片（250ms 判定）、键盘导航与 Shift 框选、拖拽框选、入场分层动效、涟漪与氛围动效 rAF；阶段 ⑥ 监听 `dataset.revision` 用 layout effect 整层重绘（不重播入场）。 |
| `components/Shmoo1DChart.tsx` | 1D 交互：hover 吸附 tooltip、入场动效、reduced-motion 降级；阶段 ⑥ 同样按 revision 直接重绘 spec 线 / 色带 / 越界标记。 |
| `components/SiteRail.tsx` | 左侧站点列表与数据集摘要、导入报告。 |
| `components/SpecPanel.tsx` | 右侧规格面板：下限/上限可直接编辑（防抖 250ms 自动应用），非法输入就地提示并保留上次有效结果；支持撤销一步与重置为文件值；最差 margin 标注撞上限/下限，二值数据显示“不适用”，切片时改显示该曲线统计。 |
| `components/StatusBar.tsx` | 底部状态栏：解析状态、真实统计、耗时；有框选时追加格数 / PASS/FAIL / 区域通过率 / value 范围与均值 / 最差 margin，并提供清除按钮。 |
| `components/TitleBar.tsx` | 自定义标题栏与「打开 CSV」按钮。 |
